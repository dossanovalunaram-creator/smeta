# Смета за 5 минут

«Смета за 5 минут» — простое веб-приложение для быстрого создания сметы или коммерческого предложения с сохранением результата в PDF.

В приложении можно указать скидку и НДС, выбрать валюту, сохранить PDF для клиента и скопировать готовую смету для отправки в WhatsApp. Текущая смета автоматически сохраняется как черновик в браузере.

Приложение предназначено для:

- предпринимателей, которым нужно подготовить коммерческое предложение клиенту;
- офисных сотрудников, которые составляют смету закупки или отчёт о расходах для руководителя.

Часто используемые работы и товары можно добавить в каталог услуг, а затем быстро переносить из него в смету. Каталог сохраняется в `localStorage` браузера и остаётся доступным после повторного открытия приложения.

## Файлы приложения

- `index.html` — структура страницы: заголовки, поля, таблица позиций и кнопки.
- `styles.css` — внешний вид приложения и адаптация интерфейса для телефона.
- `script.js` — расчёты, скидка и НДС, выбор валюты, добавление и удаление позиций, черновик, каталог услуг, копирование текста и подготовка документа к сохранению в PDF.

## Как открыть

Дважды щёлкните по файлу `index.html`. Приложение откроется в браузере; устанавливать дополнительные программы не нужно.

## Как проверить

Добавьте две позиции:

1. Количество `2`, цена `15 000`.
2. Количество `1`, цена `8 000`.

Итог должен быть: **38 000 ₸**.

Затем проверьте дополнительные возможности:

1. Укажите скидку `10%`. Сумма со скидкой должна быть **34 200 ₸**.
2. Укажите НДС `12%`. НДС должен составить **4 104 ₸**, итог к оплате — **38 304 ₸**.
3. Выберите другую валюту. Знак валюты должен измениться во всех суммах сметы.
4. Нажмите «Сохранить PDF». В окне печати проверьте реквизиты, позиции, итоговую сумму и комментарий, затем выберите сохранение в PDF.
5. Нажмите «Скопировать для WhatsApp». Должен скопироваться текст сметы; если браузер запрещает доступ к буферу обмена, приложение покажет поле для ручного копирования.
6. Измените любое поле и обновите страницу. Сохранённый черновик должен восстановиться автоматически.
7. Откройте «Каталог услуг», добавьте услугу и перенесите её в смету. После обновления страницы услуга должна остаться в каталоге благодаря сохранению в `localStorage`.
